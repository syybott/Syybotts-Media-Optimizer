# Third-party tools

The application can download but does not commit or statically bundle these
tools:

- **libwebp / cwebp**, distributed by the WebM Project under its accompanying
  license and patent grant.
- **FFmpeg / ffprobe**, obtained from Gyan's Windows builds and governed by the
  license files included in the downloaded package.
- **PS2EXE**, used only during the build process.

The downloader retains available license and README files beside installed
tools. Review those files before redistributing a release folder.
